# brickio

USB audio and MIDI for the sydilaxe TrimUI apps (TrimFX, Jaffedrone, Columbia Street, Conduit, HI5,
RadioScan...) on MustardOS: one shared library, so every app gets the same low latency, the same
devices handling and the same MIDI, and the apps can work together when connected.

GPL-3.0-or-later.
